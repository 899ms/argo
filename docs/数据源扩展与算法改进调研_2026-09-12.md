# 数据源扩展与算法改进调研_2026-09-12

> 三路并行调研（全球源 / 中文源 / 算法论文），研究性质、未实施、待拍板。
> 方法沿用《数据源盘点_2026-09-12》：免 key 端点一律 curl 实测，不凭文档承诺；主会话对六个 A 档头部候选做了二次抽查（Google News RSS / 知乎热榜匿名通道 / Bangumi / std.samr / crt.sh / 人民网搜索，全部独立复核通过）。
> 已收录 175 源、已否决项（雪球/36氪等）、已记录待办（TikHub+轻抖 / 高德 / WAQI）一律不重复。

## 总览：三个格局判断

1. **免 key 直连窗口在系统性收窄**。本轮实测直接撞墙：Qwant（DataDome）、Yep（Cloudflare）、Sourcegraph、grep.app（Vercel）、jina 匿名通道（401 强制 key）、Invidious/Piped 公共实例全灭、Bing News RSS（302 落 cn 域）、Common Crawl index、linux.do/NodeSeek（CF 挑战）。2024-2026 间开放端点大规模加墙，A 档变薄不是没找到，是加墙了。
2. **Bing Web Search API 已于 2025-08-11 全面退役**（410 Gone）。官方替代 Azure Grounding with Bing（约 $35/1k，绑定 Agent Service）对 spec 化元搜索不划算。结论：Bing 替代不必单独立项，Serper（2500 次免费）+ Google CSE（100 次/天免费）+ 已有源即可覆盖 SERP 需求。
3. **中文真空白集中在四块**：法律法规全文（flk 最值得逆向）、标准文档、港股公告、中文影视元数据；算法层最大杠杆是**域信誉层**（信任分+加权 RRF+规则 YAML 一表三用）、URL 规范化去重、QPP 分数分布判据挂接早停。

# 第三部分：元搜索改进算法/论文/工程实践

> 基线对照 argo v2.8.7：TF-IDF 意图路由 + RRF + title/url 去重 + 证据闭环 + 失败分型/节流/熔断/recovery + `_query_coverage_ok` 词面早停守卫 + 查询缓存 + research 协议 + 131 项金标门禁。

## ① 查询理解与扩展

- **multi-query / RAG-Fusion**（Rackauckas, arXiv 2402.03367, 2024；multi-query+RRF 原始实现为 Raudaschl 2023 的 GitHub 项目）：LLM 生成 3-4 个查询变体，各自检索后统一 RRF。research.py 已有扩词，普通 search 路径没有。落地：`--expand auto`（仅当路由置信度低于阈值或 zh 查 en 源时触发），变体与原查询进同一 RRF 池，标 `origin_query` 字段。**M**
- **HyDE**（Gao et al., "Precise Zero-Shot Dense Retrieval without Relevance Labels", ACL 2023, arXiv 2212.10496）：中文查询打英文源（arxiv/S2）时先由本地 LLM 生成英文假设段落再抽关键词入查询串。对纯 SERP API 收益有限，只对词面/语义匹配型源开启。**M**
- **step-back prompting**（Zheng et al., ICLR 2024, arXiv 2310.06117）：对过窄的具体问题生成上位抽象问题。落地：作为 recovery 救援链第二跳——精确查询空时先同义改写（已有），再 step-back 上位问题（新增），比直接换通用源保精度。**S**
- **伪相关反馈 PRF/RM3**（RM1: Lavrenko & Croft, SIGIR 2001；RM3 混合原查询: Abdul-Jaleel et al., UMass TREC 2004）：零 LLM 成本——从 top-10 的 title/snippet 抽高频信息词扩入重查一轮。适合 `--mode fast` 与救援链。**S-M**
- **跨语言查询翻译**：已有多语言检测；增量是**实体保护术语表**（人名/机构/产品名不翻译，保留原文双写），避免「美联储」直译丢 "Fed"。**S**

## ② 引擎选择

- **Thompson Sampling 简化版**（LinUCB 全家桶：Li, Chu, Langford & Schapire, WWW 2010, arXiv 1003.0146）：78 域×175 源组合空间太大，LinUCB 全面上是过度设计。先上简化版：每（域，引擎）对维护 Beta(成功,失败)，reward=该引擎贡献的独特命中且最终被采纳，只在路由置信度平局时打破平局。**S-M**
- **successive halving 级联**（Karnin, Koren & Somekh, ICML 2013）：先全源浅查（top-5、低超时），依早期质量信号只对 top-k 源深查翻页。对应 `--mode deep` 省钱改造。**M**
- **RouteLLM / FrugalGPT**（Ong et al., arXiv 2406.18665；Chen, Zaharia & Zou, arXiv 2305.05176）：思想迁移——fast/auto/deep 已是成本级联雏形，等 bandit 统计积累够，用历史 query→质量/采纳率日志训练轻量路由分类器替代静态配置顺序。**M-L**

## ③ 融合与排序

- **加权 RRF + 引擎可信度在线估计**：`score(d)=Σ w_e/(k+rank_e(d))`，`w_e` 来自 Beta 后验均值或「被 --verify 采纳率」EWMA。与现有 RRF 管线完全兼容。**S**（与⑧共享统计）
- **CombSUM/CombMNZ**（Fox & Shaw, "Combination of Multiple Searches", TREC-2 1994）：前提是跨引擎分数归一化（每 SERP 内 z-score）。CombMNZ（分数和×命中引擎数）奖励「多源共识」，与 argo 哲学一致；在金标 131 项上与 RRF A/B。**M**
- **learning-to-rank**（LambdaMART: Burges, arXiv 0911.0436, 2010）：特征现成（词面匹配、引擎 rank、域信任、时效性），标签来自 --verify 反馈+金标；131 项不够训练，先做特征线性组合（手动 LTR），样本上千再上。**L**
- **cross-encoder 重排 bge-reranker-v2-m3**（BAAI 2024）：多语言含中英混合，Mac 本地可跑——GGUF 量化（gpustack/bge-reranker-v2-m3-GGUF）配 llama.cpp `/rerank`，或 ONNX int8 走 CPU。落地：`--rerank local` 对 RRF top-20 重排，超时熔断降级回 RRF 顺序。**单点质量增益最大的可选件**。**M**
- **LLM listwise 重排 RankGPT**（Sun et al., "Is ChatGPT a Good Search Ranker?"? 实际标题 "Is ChatGPT Good at Search? …", EMNLP 2023, arXiv 2304.09542）：滑动窗口（window=20, stride=10）本地 LLM 重排；成本高于 cross-encoder 且本地小模型 listwise 能力有限，排后。**M**

## ④ 多样性与去重

- **URL 规范化**：去 utm_*/fbclid、除 fragment、协议/www/尾斜杠折叠、m. 归一。现 title+url 去重对「同文不同追踪参数」漏重——规范化后去重质量立升，**全表性价比最高的单点**。可借鉴 SearXNG URL 处理插件。**S**
- **SimHash 近重复**（Manku, Jain & Das Sarma, WWW 2007；MinHash 源自 Broder 1997）：title+snippet char 3-gram 64-bit SimHash，海明距离≤3 判近重；fetch 后正文 MinHash 折叠「多源同稿」。常数级计算纯 Python 可行。**S-M**
- **MMR**（Carbonell & Goldstein, SIGIR 1998）：`argmax λ·sim(d,q)−(1−λ)·max sim(d,d_selected)`，λ≈0.7，embedding 用 multilingual-e5-small/bge-m3（Mac CPU 几十 ms/条）。`--diversity` 对 top-20 去冗余（「10 条都是同一通稿」）。**M**

## ⑤ 查询性能预测 QPP——直接对应早停痛点

- **WIG**（Zhou & Croft, SIGIR 2007）：`WIG=mean(score(top10))−mean(score(全体))`，最易落地（在单引擎分数域或 RRF 融合分数上算近似）。**S**
- **NQC**（Shtok et al., "Predicting Query Performance by Query-Drift Estimation", SIGIR 2012）：top 文档得分向量与查询向量的距离范数，捕捉 top 漂移。**M**
- **clarity score**（Cronen-Townsend et al., SIGIR 2002）：查询语言模型与文档集模型的 KL 散度，低分=语义发散=查询难；snippet 词频近似。**M**
- **落地**：早停判据=覆盖 ok **且** 分数分布头部集中（`flat=(p90−p10)<eps; stop=coverage_ok and not flat and wig>τ`）。分数平坦→不早停→触发 recovery/扩查。综述：Meng et al. 2023 QPP survey。**S-M**

## ⑥ 延迟与可靠性

- **hedged requests**（Dean & Barroso, "The Tail at Scale", CACM 2013, 56(2)）：首请求超 P95×1.2 未返回再发副本取先到者。**只对免费/无限额源开**（付费源重复请求双倍计费），或 hedge 到同域族备用源。**S-M**
- **EWMA 自适应超时**：每引擎 `EWMA_p95+3σ`（重尾分布建议分位数估计如 P² 算法），时间衰减。慢源早断、快源不误杀。**S**
- **熔断器半开探测**（Nygard《Release It!》）：OPEN 冷却到期进 HALF_OPEN，放行 k=2 探测，全成才 CLOSED，任一失败回 OPEN 指数拉长冷却。argo 已有熔断，补「半开」避免恢复误判。**S**

## ⑦ 缓存策略

- **按意图分 TTL**：新闻/舆情 30-60 分钟；常青（定义/文档/学术/万年历类垂直）7-30 天；垂直结构化（火车票/油价）分钟级。缓存键已有路由信息，TTL 按主域查表。**S**
- **负缓存**：空结果/全源失败缓存 5-15 分钟，但**失败分型联动**——配额型/熔断型失败不进负缓存（源恢复应立即重试），确证型空结果才缓存。**S**
- **语义缓存**（GPTCache, zilliztech/GPTCache；论文 arXiv 编号待核）：embedding 相似度>0.95 复用。SQLite+向量列或 hnswlib 即可。**时效性查询禁用**（语义相近答案已变），仅常青域启用。**M**

## ⑧ 证据核验与可信度

- **按域贝叶斯信任分**（**全表性价比之王**）：每注册域维护 Beta(α,α₀) 先验，--verify 证据分变化（improved/degraded）作为伯努利观测更新后验；融合排序用 **Beta 分位数下界**（悲观估计）而非均值。伪代码：`trust[d]=Beta(1+improved,1+degraded); w_e ∝ Σ_d trust[d]·hits[e][d]`。URL→证据分记忆已有，聚合成域级只差一步。与③加权 RRF、⑩规则 YAML 共用一张表。**S-M**
- **Self-RAG**（Asai et al., ICLR 2024, arXiv 2310.11511）：反思令牌思想迁移——--verify 后让本地 LLM 产 ISREL/ISSUP/ISUSE 三标签写入证据记忆，后续查询复用「该 URL 支持该论断」。**M**
- **CRAG**（Yan et al., "Corrective Retrieval Augmented Generation", arXiv 2401.15884, 2024）：检索质量评估器在「改写重查/web 补搜」间纠错——recovery 救援链的学术版：触发救援前加**廉价评估门**（覆盖守卫+QPP 分数），避免「结果其实够好却白跑救援」。**S-M**
- **NLI 事实核验**（FEVER 范式: Thorne et al., NAACL 2018）：句级 NLI 小模型（0.2-0.5B，Mac CPU）对「正文 vs 断言」做 entailment/contradiction 三分类，证据分从「吸收分」升级为「立场分」；中文用 XNLI 训练的多语言模型（选型待测）。**M**
- **多源一致性投票与矛盾立场**：跨源抽取实体+数值，按口径分组冲突检测（「数字必须标口径」纪律可机械化）。**M**

## ⑨ 离线/在线评估

- **NDCG/MRR@k 持续追踪**：金标已有，CI 门禁输出指标趋势（不只 pass/fail，还要回归幅度），③④的融合改动全靠它验收。**S**
- **LLM-as-judge 位置偏差控制**（Zheng et al., MT-Bench, NeurIPS 2023, arXiv 2306.05685）：判分随机交换候选顺序、双向各判取均值；用于金标扩容（judge 弱标注→人工抽查校准）。**S-M**
- **team-draft interleaving**（大规模验证: Chapelle, Joachims, Radlinski & Yue, WSDM 2012；方法概念源自 Radlinski et al. 2008）：两版融合算法轮流当队长交织列表比采纳。argo 无浏览器点击，**落地变体**：用「最终被写进 dossier/结论的 URL」作采纳信号做离线回放。**M**

## ⑩ 结果质量先验

- **Brave Goggles**（brave.com/blog/search-anniversary/；DSL 文档在 Brave API docs）：用户自定义重排规则 DSL（boost/downrank/discard + domain/URL/模式/时间窗）。迁移：**本地域规则 YAML**（`domain: +0.5/-1.0/skip`），RRF 加权阶段生效，与⑧域信任分叠加（规则=先验，信任分=在线更新）。**S-M**
- **Kagi 反 SEO 机制**（help.kagi.com/kagi/features/slopstop.html；另见 danluu.com/seo-spam/）：按广告/追踪器密度 downrank 域。argo fetch 已抓正文，可顺带统计脚本/广告信源密度作信号；冷启动人工黑/灰名单。**S**
- **公开信任列表**：Tranco 排行（Le Pochat et al., IEEE S&P 2019, tranco-list.eu）白名单基线；EasyList 派生广告/追踪域表灰名单。**S**

## ⑪ 正文抽取质量

- **trafilatura**（Barbaresi, JLCL 2021；repo docs/evaluation.md 持续基准）：多份独立基准中 precision/recall 均衡优于 readability-lxml/jusText/boilerpipe。落地：抽取链改 `直出探测 → trafilatura（新主力）→ 现有 BM25 聚焦（回退）`，正文率/文本密度并入质量信号。纯 Python 依赖，Mac 无障碍。**S**
- **LLM 抽取路线**（Jina ReaderLM 一类 HTML→MD 小模型）：质量上限高、成本延迟高，仅作疑难站点浏览器态之后的最后一级（具体模型与基准待核）。**M**

## ⑫ CJK/中文特性

- **中文分词**：词面匹配型引擎对未分词中文长串召回差。查询侧 jieba 精确模式+领域词表，**检索侧双路**（分词后查询+原 query 双写，结果进同一 RRF 池）。**S**
- **音译人名/机构名**：内置中英对照别名词典（500-2000 条）+用户可扩充 YAML；查询改写双写（「美联储」附 "Fed"）。**S**
- **跨语言模型轻量用法**：LaBSE（Feng et al., ACL 2022, arXiv 2007.01852）/mContriever（Izacard et al., TMLR 2022, arXiv 2112.09118）/multilingual-e5-small——不替换检索：(a) zh 查询与英文结果 title 算跨语言相似度作 RRF 后加分特征（免费弱化版多语言 reranker）；(b) 给④ MMR 供 embedding。**M**
- **中文查询归一化**：全半角折叠、繁简转换（opencc）并入缓存键与去重键，避免「台灣/台湾」双重缓存。**S**

## Top 5 建议优先实施（按增益/成本）

1. **域信誉层一表三用**：域级贝叶斯信任分（⑧）+加权 RRF（③）+本地域规则 YAML（⑩）——`--verify` 记忆已有数据，只差聚合到域+进融合权重；从「结果融合」升级为「有记忆的融合」。**S-M**
2. **URL 规范化 + SimHash 近重复**（④）：现去重对追踪参数与转载稿漏判，纯函数无依赖，金标门禁可直接验收。**S**
3. **QPP 分数分布判据挂接早停与救援链**（⑤+⑥ CRAG 思想）：补齐「纯计数早停」修复后的另一半守卫——词面覆盖之外加分数分布维度；救援链前置廉价评估门省配额。**S-M**
4. **意图分 TTL + 负缓存（失败分型联动）**（⑦）：零算法风险，立刻省配额。**S**
5. **bge-reranker-v2-m3 本地 cross-encoder 重排**（③，GGUF/llama.cpp）：单点质量增益最大的可选件，多语言尤其受益；带超时熔断降级回 RRF。**M**

次优先：EWMA 自适应超时+免费源 hedged（⑥，S）；RM3 伪相关反馈+中英别名词典双写（①⑫，S-M）；trafilatura 进 fetch 抽取链（⑪，S）。
不建议现在做：全量 LinUCB（组合空间过大，先 Thompson Sampling 平局裁决）、LambdaMART（131 项金标不够训练）、GPTCache 语义缓存（时效域风险高，等 TTL 层稳定）。
