## 新增域（7 个）

`japan_law`（日本法令）、`soil_agri`（土壤/农业）、`astronomy`（天文/空间天气/卫星）、`vehicle_data`（车辆厂商/车型）、`energy`（电网碳强度）、`transport`（共享单车）、`health_org`（卫生组织）。

**触发词纪律（本轮踩坑）**：`japan_law` 初版第二条 pattern 写成
`(日本法|e-Gov|法令検索|憲法|民法|刑法)`，其中裸的「民法」「刑法」会把
「刑法 判例 司法解释」这类**纯中文**查询吸进本域——实测
`test_p0_v25::test_legal_domain` 由 `legal` 漂移到 `japan_law`。
修复：日文汉字词一律加日本语境限定（`(日本|日语|和文).{0,10}(法令|…)`），
日文假名作独立强信号 pattern。**新增窄域若用汉字词做触发，必须带语境限定。**

## 实施要点（后续维护注意）

### ⚠️ 准入层粘滞 bug（本轮最重要的修复）

**症状**：23 个新引擎全部 `routable=False`——能单跑、能 `--engine` 显式调用，
但永不参与自动路由。详情页显示 `blocked=true / reason=health_failed`，而
同一条记录里 `health.status=pass`、`quality_score=1.0`：**状态自相矛盾**。

**根因**（`scripts/engine_admission.py::record_validation`）：
`reason` 写成 `reason or current.get("reason")`，把**历史**失败原因粘滞下来。
触发序列：
1. `--stage health` 首次失败 → 留下 `reason=health_failed`
2. 修好后重跑 `--stage all --admit`：health/quality 双 pass、blocked=False
3. 本次 `reason` 为空 → 回退成历史的 `health_failed`
4. 记录自相矛盾 → 状态层判 `routable=False`

**波及范围**：24 个引擎（批次九全部 + `realtime_index`）被错误拉黑。

**修复**：reason 必须反映本次判定——本次未 block 则置空，blocked 则给
`validation_failed`（或调用方显式传入的原因）。

**为何长期未被发现**：`engine_validate` 的「收录门禁」只报 health/quality
阶段的 pass/fail，**不看准入记录本身是否自洽**；而 `--list-engines --detail`
的 blocked 字段又没人交叉核对 health.status。新增
`tests/test_engine_admission.py`（6 条）双向锁定：单测粘滞回归 + 真实状态
目录自洽门禁。**教训：任一门禁只报单个阶段结果时，「阶段通过但状态层
结论相反」这类矛盾不会被任何一环发现。**

### 其他要点

- **GDACS 的 `properties.url` 是 dict**（`{report, geometry, …}`）而非字符串，直接透传会在下游 `url.lower()` 处抛 AttributeError；builder 取 `report`→`geometry`→兜底首页。
- **OBIS/WoRMS 的 ASCII 守卫**：中文俗名对二者无意义（返回无关属种），纯中文查询直接诚实空，交回百科类引擎。守卫不可删——离线测试用「mock 出数据 + 中文查询」双向锁定，防退化为空转测试。
- **e-Gov 响应可达 2.7MB**，http.client 偶发 `IncompleteRead`；builder 接受 partial 数据（`_read` 帮手）而非直接失败。
- **WHO DON 不传 `$top`/`$orderby`**：未编码的 `$` 参数在该网关返回 400，改为取回后本地按日期排序 + 查询词命中优先。
- **jikan / soilgrids 主动禁用**：上游端点故障（504 / values 全 null），builder 逻辑已验证正确。测试 `TestDisabledUpstreamFaults` 锁定 `enabled:false`，防止误改。上游恢复后改回 `true` 即可，无需改代码。
- **NHTSA vPIC / OpenF1 / Art Institute 为两跳结构**：先取列表再取详情/模型，builder 内控条数上限。
- **接入新域时不要覆盖既有 primary**：本轮中断前的批量接线曾把 6 个既有域的
  `primary` 改成新引擎（species→obis、art→artic、anime→bangumi、book→open_library、
  sports→jolpica、media→deezer），改变了老域的答案源语义。已全部恢复：
  新源作为平行候选加入 combo，不抢 primary。
