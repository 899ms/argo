# RELEASE_NOTES_v2.8.8

相对 v2.8.7 的改进：搜索源 175 → 191，全部免密钥开箱可用。

## 新增能力：16 个数据源

- **法律法规**（此前只有裁判文书，缺法条本身）：国家法律法规数据库 flk_law——法律/行政法规/司法解释/地方性法规的权威文本，问「民法典第 X 条」「XX 法全文」直接出官方条文与全文页链接；gov_regulations 补部门规章/地方规章层。
- **国家标准**：std_samr（全国标准信息平台，标准号/状态/实施日期）+ openstd（全文预览入口）。问「数据安全 国标」「GB/T 45577」不再只能翻网页。
- **新闻**：人民网（权威综合中文新闻）+ Google News RSS（多语言，支持 `when:1d` 时间窗与 `site:` 限定）。
- **生活/娱乐**：豆瓣电影（中文片名视角）、Bangumi（番剧/漫画/游戏条目元数据）、网易云音乐、汉典（字义/音韵/字源）、维基文库（古文引文溯源）。
- **安全/资产**：crt.sh 证书透明度（子域名/钓鱼域情报，与 NVD 漏洞情报互补）。
- **其他**：少数派（效率/数码内容）、Met Museum 藏品库（艺术/博物馆空白补位）、NASA 图像库、知乎热榜免密钥通道（不再占用开放平台 100 次/天配额）。

## 既有引擎扩展

- **stackoverflow → Stack Exchange 站点族**：`argo search "site:serverfault nginx 超时"` 直查 serverfault 等 180+ 站点；无前缀行为不变。

## 框架修复

- **HTTP 客户端重定向修复**：部分站点 301 的 Location 带未编码中文（如汉典 `/hans/道`），此前二次请求会直接 UnicodeEncodeError 失败；现在自动还原并补编码。对所有 GET 型引擎生效。

## 默认关闭功能的打开方式

- 本批 16 源全部默认开启（免密钥、自动路由会用上）。显式调用：`argo search "行政处罚法" --engine flk_law`、`--engine std_samr`、`--engine crt_sh` 等，全量清单 `argo search --list-engines`。
- Stack Exchange 站点族无需配置：查询里写 `site:<站点名>` 即可。

## 相关依赖与已知边界

- 无新增第三方依赖。
- flk_law 服务端偶发 TLS 层掐断（已内置单次退避重试），仍可能偶发空结果，聚合层自动换源补位。
- crt.sh 响应偏慢（10-40s 常态），高后果场景再显式调用。
- HKEXnews（港股公告）本轮未收录：公告接口服务端已停止返回数据，待其恢复或找到替代路径后单独立项。
