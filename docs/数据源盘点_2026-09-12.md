## 与既有短板的呼应

- security 是完全空白域（coverage 分布里无此项），A 档 1/2/3 一次补齐三条线：包安全（deps.dev）、漏洞情报（nvd）、生命周期（endoflife.date）。
- academic 域的「评审可见性」与「预印本时效」两个缺口分别由 openreview/biorxiv 补上，与 openalex/semantic_scholar 形成互补而非重叠。
- macro/finance 域补双边贸易（un_comtrade）后，宏观事实核查链路完整：国内（nbs_stats）→ 美国（fred）→ 欧盟（eurostat）→ 全球（worldbank）→ 贸易流（comtrade）。

## 接入纪律提醒

- 每个新引擎过三道门：`engine_validate --stage all --admit` + 全量 pytest + live 冒烟。
- 需要 key 的（B 档）先在 spec 里声明 env 占位符与 requires，未配置时自动退化匿名/跳过，与既有引擎行为一致。
- 域族节流：deps.dev/openreview/nvd 等有明确配额契约的 API 不进节流表；遵守配额写进 spec 注释。
